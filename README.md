# MCQ Generator

A simple web-based MCQ (Multiple Choice Question) generator.

## Live Site:
https://mcqmake.vercel.app

## Features
- Create MCQ instantly
- Clean and mobile-friendly design
- Download MCQ as high-quality image
- Random image file name
- Auto-deployed with Vercel

## Live Demo
This project is deployed using Vercel.

## How to Use
1. Enter your question
2. Fill in options A, B, C, and D
3. Click **Generate MCQ**
4. Click **Download Image**

- HTML
